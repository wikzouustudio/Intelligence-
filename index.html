Comment installer Ollama (5 minutes)
  1. Télécharge et installe Ollama depuis ollama.com.
  2. Ouvre l'Invite de commandes (touche Windows, tape « cmd ») et installe un cerveau selon ta carte graphique :
    8 Go : ollama pull qwen2.5:7b
    12 Go : ollama pull qwen2.5:14b
    16 à 24 Go : ollama pull qwen2.5:32b
    Pour le code : ollama pull qwen2.5-coder:14b
  3. Autorise HMI à parler à Ollama :
    setx OLLAMA_ORIGINS "https://wikzouustudio.github.io"
  4. Quitte Ollama (icône près de l'horloge → Quit) puis relance-le.
  5. Reviens ici, clique sur Connecter et choisis ton cerveau. Si le navigateur demande l'accès au réseau local, accepte.
